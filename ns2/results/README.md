# NS2 lab results

Put the files from each real NS2 run in the college lab here, one folder per run, for example:

```
ns2/results/2026-10-20/
  netmind.tr           trace file (analyse with: python -m netmind ns2 ns2/results/2026-10-20/netmind.tr)
  netmind.nam          NAM animation
  ns_run_output.txt    console output of `ns netmind_scenario.tcl`
  check_output.txt     output of `python3 check_trace.py netmind.tr`
  screenshots/         NAM and terminal screenshots
```
